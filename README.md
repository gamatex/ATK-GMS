# ATK GMS Android

## Build tanpa Android Studio

1. Buat repository GitHub baru.
2. Unggah seluruh isi folder ini ke root repository.
3. Buka tab Actions lalu pilih Build ATK GMS APK.
4. Tekan Run workflow.
5. Unduh artifact ATK-GMS-APK.
6. Ekstrak ZIP artifact lalu pasang app-debug.apk.

APK debug ditujukan untuk distribusi internal, bukan Google Play.
